# e-plantShopping

This project is a modern plant shopping application built with React and Redux. The e-plantShopping app lets users browse a catalog of indoor plants, add products to the cart, update quantities, and review the total cost before checkout.

## Features

- Responsive product grid for different plant options
- Add-to-cart functionality powered by Redux state management
- Quantity updates and removal from the cart
- Live subtotal and overall total calculations
- Clean shopping flow with continue-shopping and checkout actions

## Repository

This project is named e-plantShopping and is intended to serve as the repository for the green shopping experience.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deployment

The project is prepared for GitHub Pages deployment using the gh-pages package and the base path configured for the e-plantShopping repository.
